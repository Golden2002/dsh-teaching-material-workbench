# 教学语言规范（PAEG 集成）

本插件的中文教学语言检查来自 PAEG teaching-language skill（作者 Golden2002，MIT）：
<https://github.com/Golden2002/paeg-teaching-language-skill>

## 覆盖什么

规则库在 `lib/language-data.json`，包括：

- 34 条违禁词：口语化（说白了、一下子、搞定）、网络与营销语（干货、抓手、神器）、比喻式（包袱、骨架、建筑材料）、笔记体（记住、必记、口诀、得分点）。
- 12 条可机械替换项（长词优先，例如 包袱→限定、搞定→完成、记住→掌握）。
- 标点与数字规则：并列加号/斜杠、半角标点与括号混入中文、省略号与“等”连用、破折号与“即”连用、层级编号用阿拉伯数字、标题末尾句号。
- 语体规则：行首祈使式讲解（记住、先看、注意背）、第二人称、单句超过 40 个汉字。

检查器只覆盖可枚举的问题。比喻是否恰当、句子是否通顺、术语是否与学科一致，仍要人工终审。

## 三个入口

1. **工具**：`teaching_language_check`，传 `text` 或 `directory`，返回违例（文件:行、命中、建议）、分类计数和机械替换预览。
2. **门禁**：`E2-language-paeg`。案例目录有 `language.md`（学生可见正文）时检查；没有则记“未执行”，不当作通过。
3. **Web UI**：左侧选案例，打开 `language.md` 或其他文本，点“语言检查”；结果列出分类、位置与建议，可一键应用机械替换，再由教师人工复核。

## 边界

- 只检查中文教学书面语；英文例句整体跳过。
- 教师实施包、课堂口语、文学文本不适用同一套语体规则；需要检查时把对应正文放进 `language.md` 或直接传 `text`。
- 不替代 GB/T 15834—2011、GB/T 15835—2011 的完整条款核对。

## 许可

PAEG 规则与文档为 MIT，本插件保留来源说明；规则文件与上游同步时更新 `lib/language-data.json` 的 `version` 与 `source` 字段。
